## The Philosophy of Operation Aetherfall

At Nexus Dynamics, corporate executives developed **SENTINEL-AI** behind closed doors as proprietary, black-box surveillance software. Without open source scrutiny, the software was abused to spy on engineers, harvest private credentials, and stage internal coverups.

Dr. Elena Rostova—an alumna and passionate advocate of software freedom—believed in the foundational FOSS principle:
> *"Proprietary software demands blind trust; Free & Open Source software guarantees verifiable truth."*

### Why Git Was Chosen as the Evidence Chain
Elena used Git—the decentralized, open-source version control system created by Linus Torvalds:
1. **Cryptographic Immutability:** Commits in Git are cryptographically hashed. Even when John Vance attempted to sanitize the recovery token in `main.py`, Git's commit DAG preserved the deleted lines.
2. **Distributed Repositories:** Elena mirrored the surveillance telemetry across multiple repositories on GitHub:
   - Primary Crime Scene: `https://github.com/anjo2007/operation-aetherfall`
   - Perimeter Camera Relay: `https://github.com/anjo2007/nexus-perimeter-telemetry`
   - Off-Campus Safehouse Node: `https://github.com/anjo2007/aether-safehouse-node`
3. **Decentralized Survival:** Even if the central workstation in Room 304 is erased by the 2-hour wipe countdown, the distributed open-source nodes ensure the evidence survives.

### Directive for Investigators
- Use open source command-line tools: `git log -p`, `curl`, `python`, `grep`, `file`, `diff`.
- Pay attention to Git commit logs—a backup shows what the present copy forgot.
- Reconcile the logs, identify the inside traitor, decrypt the perimeter chimes, and lock the safehouse coordinates before the 2-hour server wipe triggers!
